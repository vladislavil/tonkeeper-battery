**Структура проекта**
/node_modules - js библиотеки
/src - основная директория с файлами проекта
    /assets - содержит шрифты и изображения
    /scripts - js-код
    /styles
        /common - набор вспомагетельных инструментов для работы с scss. Миксимны, scss-переменные, базовые стили, подключение шрифтов
        /layout - написание стилий для foter, header и описание базовых стилей для основного контента
        /sections - стили для секций страницы
    main.ts - подключение всех скриптов и стилей
.gitingnore - файлы и каталоги, которые игнорируются гитом
index1.html - верстка страницы
package.json - скрипты запуска сборки и описание зависимостей
tsconfig.json - файл конфигурации typescript
vite.comfig.ts - конфигурация сборки
